How to Use Our Free Online Tools

Welcome to My Online Tools. This guide explains how to use our free tools for images, videos, audio, PDFs, text, and documents.

1. Image Tool

Use the Image Tool to resize or compress an image. Select an image, enter your preferred dimensions, choose the quality and output format, and download the result. Check the downloaded image to make sure it meets your needs.

2. Video Tool

Use the Video Tool to trim a video. Select a video file, enter the start and end times, and download the trimmed result. Preview the output before using or sharing it.

3. Audio Tool

Use the Audio Tool to trim an audio file. Select your audio, set the start and end times, and download the result. Play the downloaded file to check that the desired section was saved.

4. PDF Tool

Choose a PDF file and use the available PDF tool options. Download the resulting file and open it to confirm that it works correctly. Keep a copy of your original PDF.

5. Text Tool

Use the Text Tool to count words and characters. You can enter or paste text, copy the result, download it, or clear the text when finished.

6. Document Tool

Select a supported DOC, DOCX, or TXT file. Where available, use the text extraction option to view or copy the text and download it as a TXT file. Keep the original document for reference.

Helpful Tips

  • Use supported file formats and check the selected file before starting.
  • Review downloaded files to confirm the results.
  • Keep a backup of important original files.
  • Do not upload private or sensitive files to a website unless you understand how they are handled.
